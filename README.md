## 📖 Sobre el proyecto

Este portfolio nace con un objetivo muy claro:

No quería únicamente crear una página donde mostrar mis proyectos, sino construir un espacio que reflejara mi evolución como desarrollador, mi forma de trabajar y todo lo que voy aprendiendo durante mi formación.

Durante el desarrollo he priorizado:

- Diseño limpio y moderno.
- Alto rendimiento.
- Responsive Design.
- Componentización.
- Animaciones suaves para mejorar la experiencia de usuario.
- Código organizado y fácil de mantener.

Este proyecto seguirá evolucionando con nuevas funcionalidades y mejoras.

## 🚀 Instalación

Clona el repositorio:

```bash
git clone https://github.com/juancamilo99-prog/portfolio-astro-tailwind.git
```

Accede al proyecto:

```bash
cd portfolio-astro-tailwind
```

Instala las dependencias:

```bash
npm install
```

Inicia el servidor:

```bash
npm run dev
```
